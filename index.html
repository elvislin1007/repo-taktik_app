GitHub 設定

保存的單位會直接 commit 到這個 repo 的 units/陣營/子陣營/。 單位資料是公開的（玩家用「單位圖鑑」不用權杖就能看）；保存需要權杖，權杖只存在這台電腦的瀏覽器裡，只會送給 GitHub。

怎麼拿權杖？

repo 擁有者本人：

  1. GitHub 右上角頭像 → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token。
  2. Repository access 選 Only select repositories，只勾 repo-taktik_app。
  3. Permissions → Repository permissions → Contents：Read and write，其他都不用開。
  4. 產生後複製，貼到上面「權杖」欄，按儲存。

其他人（GitHub 的限制：要寫入別人帳號底下的 repo，fine-grained 權杖做不到）：

  1. 先請擁有者把你加為 repo-taktik_app 的協作者（Settings → Collaborators），並在信箱接受邀請。
  2. GitHub 右上角頭像 → Settings → Developer settings → Personal access tokens → Tokens (classic) → Generate new token (classic)。
  3. 只勾 public_repo，設一個到期日；產生後貼到上面「權杖」欄。這個權杖能寫入你能寫的所有公開 repo，請只用在這裡、不要外流。
保存時照這兩欄分類（必填）；空白時會先帶入關鍵字列的前兩個詞
