單位圖鑑

設定

單位資料放在私人 GitHub repo，要有權杖才讀得到。權杖只存在這台裝置的瀏覽器裡，和「算分編輯器」共用。

進階：資料來源
怎麼拿權杖？
  1. 請 repo 擁有者把你加為協作者，並到信箱接受邀請。
  2. GitHub → 右上頭像 → Settings → Developer settings → Personal access tokens → Tokens (classic) → Generate new token (classic)。
  3. 勾 repo，設到期日，產生後貼到上面。（repo 擁有者本人可以改用 Fine-grained token，只開這個 repo 的 Contents 權限）
